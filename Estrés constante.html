😰 Estrés constante

Entenderlo es el primer paso para aprender a manejarlo.

¿Qué es?

El estrés es una respuesta natural del cuerpo y la mente cuando una persona enfrenta situaciones que percibe como difíciles, exigentes o preocupantes.

Una cantidad moderada de estrés puede ayudarnos a reaccionar ante determinados retos, pero cuando se mantiene durante mucho tiempo puede afectar el bienestar y las actividades diarias.

🔎 ¿POR QUÉ OCURRE?

El estrés puede aparecer por diferentes situaciones. Algunas pueden ser:

📚 Exceso de tareas o responsabilidades.
👨‍👩‍👧 Problemas familiares o personales.
💰 Dificultades económicas.
🎓 Presión académica.
🤝 Conflictos con otras personas.
🔄 Cambios importantes en la vida.
⏰ Falta de tiempo para descansar.
💭 Preocupaciones sobre el futuro.
📋 Demasiadas actividades al mismo tiempo.
🎯 Expectativas muy altas.

❤️ SÍNTOMAS DEL ESTRÉS CONSTANTE

🫀 Físicos

  • Cansancio constante
  • Dolores de cabeza
  • Problemas para dormir
  • Tensión muscular
  • Malestar estomacal

🧠 Emocionales

  • Preocupación
  • Irritabilidad
  • Tristeza o desánimo
  • Dificultad para concentrarse

📅 En la vida diaria

  • Bajo rendimiento
  • Falta de motivación
  • Dificultad para organizarse
  • Postergación de tareas
